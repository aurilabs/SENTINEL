# Transport Sandbox

This folder is for mechanism-learning models, not publication claims.

The first model will examine characteristic ingress time scales through an idealized coating using Fickian diffusion:

```
t_D ~ L^2 / D
```

where `L` is coating thickness and `D` is an effective diffusivity.

The purpose is to build intuition for:
- why coating thickness matters
- why water/ion transport can precede visible corrosion
- why a diagnostic interphase can respond on a different time scale from the external environment

COMSOL will be introduced only after the boundary conditions, species, and physical question are well defined.
